📦 Pérdida de Paquetes (Packet Loss Rate)
PDR = Packet Delivery Ratio. Las sesiones cercanas al gateway (Jona_1, 2, 6, 30_09) logran 0% de pérdida. Los recorridos extendidos con SF7 superan el 90% de pérdida más allá de ~300 m. Con SF9 se mantiene conectividad parcial hasta mayor distancia, aunque el gateway en este despliegue no responde con SF10 (DR2 parece no estar habilitado).

🔊 Análisis de Piso de Ruido — NoiseAnalyze
Se realizaron 52 escaneos espectrales (NoiseAnalyze) en la banda AU915 (915–928 MHz) en distintas fechas y ubicaciones. El piso de ruido promedio se mantiene entre −74 y −70 dBm, consistente con entorno urbano/semiurbano. Esto implica un margen de sensibilidad efectiva de ~50 dB sobre el ruido para señales Strong.

⚙️ Análisis por Spreading Factor (SF)
Las pruebas usan SF7–SF10 a 30 dBm. SF9 es el más usado en recorridos de cobertura. SF7 ofrece la mayor tasa de datos pero menor alcance. SF10 no es respondido por el gateway en este despliegue (posiblemente DR2 deshabilitado en el perfil de dispositivo).
